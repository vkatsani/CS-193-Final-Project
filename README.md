# CS 193 Final Project

This is a Java program that gives a certain number of reminders to complete tasks/events based on their difficulty that the user indicates. 

## The Problem

Sometimes you underestimate the difficulty of a task (like homework or studying), so it takes longer than you intended, causing unnecessary stress and scheduling conflicts. This program is a planner that you can take note of task difficulty in, and the program will give a varying amount of prior reminders to complete the task based on its difficulty level.
